# dcapi 实时语音调用指南

本文说明如何在 dcapi 中使用实时语音输入输出能力，直接与大模型建立语音对话。

当前推荐优先使用以下两个接口：

- `dc.aiproxy.CreateRealtimeVoiceSession`
- `dc.aiproxy.CreateAliyunRealtimeVoiceSession`

其中：

- `CreateRealtimeVoiceSession` 适合任意 provider，只要你能提供协议适配器。
- `CreateAliyunRealtimeVoiceSession` 内置了阿里云 DashScope realtime 语音事件适配，适合直接接阿里云实时语音/多模态模型。

## 1. 能力说明

实时语音会话由三层组成：

1. `DoAIProxyCall` 先向代理服务获取当前会话的动态鉴权信息。
2. `CreateRealtimeAudioSession` 负责建立和维护 realtime WebSocket。
3. `CreateRealtimeVoiceSession` 在 WebSocket 之上继续处理：
   - 麦克风采集
   - 音频帧发送
   - 服务端事件解析
   - 输出音频播放

dcapi 当前已经内置：

- 浏览器默认输入适配器：`createBrowserRealtimeVoiceInputAdapter`
- 浏览器默认输出适配器：`createBrowserRealtimeVoiceOutputAdapter`
- 微信小程序 socket 工厂：`createWechatMiniProgramRealtimeSocketFactory`
- 微信小程序录音适配器：`createWechatMiniProgramVoiceInputAdapter`
- 阿里云默认协议适配器：`createAliyunRealtimeVoiceProtocolAdapter`

## 2. 接入前提

### 2.1 服务配置

你的 AI 代理服务配置需要包含 realtime 静态配置。核心字段通常如下：

```json
{
  "service": "aliyun-realtime",
  "host": "dashscope.aliyuncs.com",
  "path": "/compatible-mode/v1/chat/completions",
  "authorization": "Bearer {{server-side-key}}",
  "realtime": {
    "enabled": true,
    "connection": {
      "protocol": "WebSocket",
      "url": "wss://dashscope.aliyuncs.com/api-ws/v1/inference?model=qwen-omni-turbo-realtime",
      "authMode": "apikey",
      "authQueryName": "api_key"
    },
    "response": {
      "customResponse": true,
      "actualDataField": "providerData"
    }
  }
}
```

说明：

- `realtime.connection` 描述静态连接模板。
- `realtime.response` 描述代理包装 realtime 鉴权返回时的结构。
- 动态 token / api_key 仍由真实下游服务返回，dcnode 只在 realtime 鉴权请求时做包装。

### 2.2 浏览器握手限制

如果 realtime 鉴权采用 `bearer` 模式，需要注意：

- 浏览器原生 `WebSocket` 不能直接带自定义 `Authorization` 头。
- 这类场景优先改成 query/token 透传。
- 如果必须走 header，需要传 `createWebSocket` 注入支持自定义握手头的运行时。

### 2.3 用户手势要求

浏览器音频播放通常受自动播放策略限制。实际页面里应在用户点击按钮后再调用：

- `CreateRealtimeVoiceSession`
- `startVoiceInput`

## 3. 核心接口

### 3.1 通用接口

```ts
const [voiceSession, error] = await dc.aiproxy.CreateRealtimeVoiceSession({
  initRequestBody: { scene: "voice-chat" },
  appId,
  themeAuthor,
  configTheme,
  serviceName,
  runtime: "browser",
  protocolAdapter,
});
```

### 3.2 阿里云快捷接口

```ts
const [voiceSession, error] = await dc.aiproxy.CreateAliyunRealtimeVoiceSession({
  initRequestBody: { scene: "voice-chat" },
  appId,
  themeAuthor,
  configTheme,
  serviceName,
  model: "qwen-omni-turbo-realtime",
  runtime: "browser",
});
```

### 3.3 会话对象能力

`IAIProxyRealtimeVoiceSession` 提供：

- `connect()`
- `startVoiceInput()`
- `stopVoiceInput(options?)`
- `sendText(text)`
- `sendEvent(data)`
- `commitInput()`
- `requestResponse()`
- `finishSession()`
- `close(code?, reason?)`

## 4. 浏览器开箱示例

这个示例适用于：

- PC 浏览器
- 移动 H5
- 微信浏览器

```ts
import { DC } from "web-dc-api";

const dc = new DC({
  wssUrl: "wss://dcchain.baybird.cn",
  backWssUrl: "wss://dcchain.baybird.cn",
  appInfo: {
    appId: "your-app-id",
    appName: "Realtime Voice Demo",
    appVersion: "1.0.0",
    appIcon: "",
    appDesc: "",
  },
});

let voiceSession: Awaited<ReturnType<typeof createVoiceSession>> | null = null;

async function initDC() {
  const ok = await dc.init();
  if (!ok) {
    throw new Error("dc 初始化失败");
  }

  const [accountInfo, loginError] = await dc.auth.accountLoginWithWallet();
  if (loginError || !accountInfo) {
    throw loginError || new Error("登录失败");
  }

  const configError = await dc.aiproxy.SetAICallConfig({
    appId: "your-app-id",
    themeAuthor: "theme-author-public-key",
    configTheme: "default",
    serviceName: "aliyun-realtime",
    headers: {
      "Content-Type": "application/json",
    },
    path: "/compatible-mode/v1/chat/completions",
    model: "qwen-omni-turbo-realtime",
  });

  if (configError) {
    throw configError;
  }
}

async function createVoiceSession() {
  const [session, error] = await dc.aiproxy.CreateAliyunRealtimeVoiceSession({
    initRequestBody: {
      scene: "voice-chat",
      user_id: dc.publicKey?.toString() || "anonymous",
    },
    model: "qwen-omni-turbo-realtime",
    runtime: "browser",
    autoStartInput: false,
    stopVoiceInputOptions: {
      commit: true,
      requestResponse: true,
    },
    aliyunProtocolOptions: {
      session: {
        input_audio_format: "pcm16",
        output_audio_format: "pcm16",
        sample_rate: 16000,
        voice: "longxiaochun_v2",
        instructions: "你是一个中文语音助手，请简短回答。",
      },
      response: {
        modalities: ["audio", "text"],
      },
    },
    onConnected(_transport, authInfo) {
      console.log("realtime connected", authInfo.websocketUrl || authInfo.url);
    },
    onModelEvent(message) {
      console.log("model event", message);
    },
    onVoiceOutputFrame(frame) {
      console.log("output frame", frame.sampleRate, frame.format);
    },
    onVoiceError(error) {
      console.error("voice error", error);
    },
  });

  if (error || !session) {
    throw error || new Error("创建实时语音会话失败");
  }

  return session;
}

async function startTalking() {
  if (!voiceSession) {
    voiceSession = await createVoiceSession();
  }

  await voiceSession.startVoiceInput();
}

async function stopTalking() {
  if (!voiceSession) {
    return;
  }

  await voiceSession.stopVoiceInput({
    commit: true,
    requestResponse: true,
  });
}

async function sendTextFallback(text: string) {
  if (!voiceSession) {
    voiceSession = await createVoiceSession();
  }
  await voiceSession.sendText(text);
  await voiceSession.requestResponse();
}

async function destroyVoiceSession() {
  if (!voiceSession) {
    return;
  }
  await voiceSession.close(1000, "manual close");
  voiceSession = null;
}

void initDC();
```

建议页面按钮流程：

1. 用户点击“开始对话”按钮时调用 `startTalking()`
2. 用户松开按钮或点击“结束发言”时调用 `stopTalking()`
3. 页面销毁时调用 `destroyVoiceSession()`

## 5. 通用 provider 示例

如果你的 provider 事件格式不是阿里云默认格式，可以使用通用接口，并自己提供协议适配器。

```ts
import {
  AIProxyRealtimeVoiceProtocolAdapter,
  AIProxyRealtimeVoiceInputFrame,
} from "web-dc-api";

function encodePcmBase64(frame: AIProxyRealtimeVoiceInputFrame): string {
  const bytes = frame.data instanceof ArrayBuffer
    ? new Uint8Array(frame.data)
    : ArrayBuffer.isView(frame.data)
      ? new Uint8Array(frame.data.buffer, frame.data.byteOffset, frame.data.byteLength)
      : new Uint8Array();

  let binary = "";
  for (const byte of bytes) {
    binary += String.fromCharCode(byte);
  }
  return btoa(binary);
}

function decodePcmBase64(value: string): ArrayBuffer {
  const binary = atob(value);
  const bytes = new Uint8Array(binary.length);
  for (let i = 0; i < binary.length; i++) {
    bytes[i] = binary.charCodeAt(i);
  }
  return bytes.buffer;
}

const protocolAdapter: AIProxyRealtimeVoiceProtocolAdapter = {
  buildConnectMessages() {
    return {
      type: "session.update",
      session: {
        sample_rate: 16000,
        input_audio_format: "pcm16",
      },
    };
  },
  buildAudioInputMessages(frame) {
    return {
      type: "input_audio_buffer.append",
      audio: encodePcmBase64(frame),
    };
  },
  buildCommitMessages() {
    return {
      type: "input_audio_buffer.commit",
    };
  },
  buildResponseCreateMessages() {
    return {
      type: "response.create",
    };
  },
  buildFinishMessages() {
    return {
      type: "session.finish",
    };
  },
  extractOutputFrames(message) {
    if (!message || typeof message !== "object") {
      return null;
    }
    const payload = message as Record<string, unknown>;
    if (payload.type !== "response.audio.delta" || typeof payload.delta !== "string") {
      return null;
    }

    return {
      data: decodePcmBase64(payload.delta),
      format: "pcm16",
      sampleRate: 24000,
      channels: 1,
      metadata: payload,
    };
  },
};

const [voiceSession, error] = await dc.aiproxy.CreateRealtimeVoiceSession({
  initRequestBody: {
    scene: "custom-provider-realtime",
  },
  appId: "your-app-id",
  themeAuthor: "theme-author-public-key",
  configTheme: "default",
  serviceName: "custom-realtime",
  runtime: "browser",
  protocolAdapter,
});
```

## 6. 微信小程序示例

dcapi 在小程序环境下支持两类适配：

1. 自动补 `connectSocket`
2. 自动补录音输入适配器

但小程序的“PCM 增量播放”能力依赖具体宿主环境，通常需要你注入 `outputAdapter`。

```ts
import {
  createWechatMiniProgramRealtimeSocketFactory,
  createWechatMiniProgramVoiceInputAdapter,
  IAIProxyRealtimeVoiceOutputAdapter,
} from "web-dc-api";

const miniProgramOutputAdapter: IAIProxyRealtimeVoiceOutputAdapter = {
  async start() {
    console.log("mini program output ready");
  },
  async play(frame) {
    // 这里按你的运行时实现：
    // 1. 如果宿主支持 PCM 流式播放，可直接写入播放器
    // 2. 如果宿主只支持 URL / 文件，可先缓存拼包后再播放
    console.log("mini program audio frame", frame);
  },
  async stop() {
    console.log("mini program output stopped");
  },
};

const [voiceSession, error] = await dc.aiproxy.CreateAliyunRealtimeVoiceSession({
  initRequestBody: {
    scene: "mini-program-voice-chat",
  },
  appId: "your-app-id",
  themeAuthor: "theme-author-public-key",
  configTheme: "default",
  serviceName: "aliyun-realtime",
  model: "qwen-omni-turbo-realtime",
  runtime: "mini-program",
  createWebSocket: createWechatMiniProgramRealtimeSocketFactory(wx),
  inputAdapter: createWechatMiniProgramVoiceInputAdapter({
    wx,
    recorderOptions: {
      sampleRate: 16000,
      numberOfChannels: 1,
      format: "pcm",
      frameSize: 2,
    },
  }),
  outputAdapter: miniProgramOutputAdapter,
  aliyunProtocolOptions: {
    session: {
      input_audio_format: "pcm16",
      output_audio_format: "pcm16",
      sample_rate: 16000,
    },
  },
});

if (error || !voiceSession) {
  throw error || new Error("创建实时语音会话失败");
}

await voiceSession.startVoiceInput();
await voiceSession.stopVoiceInput({ commit: true, requestResponse: true });
```

如果你已经有自定义小程序 socket / 录音 / 播放器封装，也可以完全不使用内置 helper，直接传：

- `createWebSocket`
- `inputAdapter`
- `outputAdapter`

## 7. 推荐的页面交互模型

### 模式 A: 按住说话

适合移动端。

```ts
await voiceSession.startVoiceInput();
// 用户说话...
await voiceSession.stopVoiceInput({
  commit: true,
  requestResponse: true,
});
```

### 模式 B: 持续监听

适合桌面 Web 会议助手或实时字幕场景。

```ts
await voiceSession.startVoiceInput();

// 由 VAD 或业务策略决定何时 commit / requestResponse
await voiceSession.commitInput();
await voiceSession.requestResponse();
```

### 模式 C: 文本和语音混合

```ts
await voiceSession.sendText("请总结一下刚才这段对话");
await voiceSession.requestResponse();
```

## 8. 事件与回调建议

可重点关注这些回调：

- `onConnected`: realtime WebSocket 已连接
- `onModelEvent`: 收到服务端 JSON 事件
- `onVoiceInputFrame`: 本地采集到一帧输入音频
- `onVoiceOutputFrame`: 解出一帧输出音频
- `onVoiceError`: 语音链路错误
- `onError`: 底层 WebSocket/transport 错误

浏览器调试时建议同时打印：

```ts
onModelEvent(message) {
  console.log("realtime event", message);
}

onVoiceError(error) {
  console.error("voice error", error);
}
```

## 9. 常见问题

### 9.1 浏览器报“无法在握手时附带自定义请求头”

原因：

- 当前环境在使用原生 `WebSocket`
- 鉴权模式要求通过 header 透传 bearer/token

解决：

1. 优先改成 query/token 透传
2. 或传入 `createWebSocket`，使用支持自定义握手头的运行时

### 9.2 浏览器可以采集但没有声音

常见原因：

- 页面没有用户手势，浏览器阻止播放
- provider 返回的不是 PCM16，但你按 PCM16 在播
- 小程序场景没注入 `outputAdapter`

### 9.3 stopVoiceInput 后模型没返回结果

检查以下几点：

1. 是否发送了 `commit`
2. 是否发送了 `response.create`
3. provider 是否是 VAD 自动断句模式
4. 你的协议适配器是否正确实现了 `buildCommitMessages` / `buildResponseCreateMessages`

### 9.4 小程序为什么没有默认输出播放器

因为不同小程序宿主对“原始 PCM 增量播放”的支持差异较大，dcapi 只统一抽象播放接口，不强行内置一个不稳定实现。

## 10. 推荐做法

1. 阿里云场景优先使用 `CreateAliyunRealtimeVoiceSession`
2. 浏览器端先走默认 input/output adapter，验证链路跑通
3. 小程序端优先复用内置 socket + 录音 helper，再单独接你自己的播放器
4. 如果要兼容多家 provider，把差异集中收敛到 `protocolAdapter`
